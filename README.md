# @kwaa/skills

kwaa's [Agent Skills](https://agentskills.io).

## Setup

### Skill Pack

```bash
pnpm add -D skills-npm @kwaa/skills
pnpm exec skills-npm setup
```

### Original Skills

```bash
pnpx skills add kwaa/skills
```
